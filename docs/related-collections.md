# Related collections

[Overview](../README.md)

Use these to broaden discovery, then return to each paper's primary source. Inclusion here is not an endorsement of every annotation or an assurance of exhaustive coverage.

| Collection | Useful perspective |
| --- | --- |
| [ANative-Lab / Awesome Self-Evolving Agents](https://github.com/ANative-Lab/Awesome-Self-Evolving-Agents) | Companion to the comprehensive survey of evolving agent systems. |
| [XMUDeepLIT / Awesome Self-Evolving Agents](https://github.com/XMUDeepLIT/Awesome-Self-Evolving-Agents) | Companion to the what/when/how/where survey. |
| [Self-Improving Agents survey collection](https://github.com/selfimproving-agent/Awesome-Self-Improving-Agents) | Model and scaffold improvement, with a broad survey bibliography. |
| [sukoji / Awesome Self-Evolving Agents](https://github.com/sukoji/awesome-self-evolving-agents) | Mechanism-oriented map with learning paths, recursive improvement, and failure discussions. |
| [Awesome Reliable Text-to-SQL](https://github.com/duyvuleo/awesome-reliable-text-to-sql) | Companion on ambiguity, clarification, answerability, and evaluation. |
| [Awesome AI Co-Scientist](https://github.com/duyvuleo/awesome-ai-co-scientist) | Companion on scientific agents, experimental evidence, and research workflows. |

This collection emphasizes learning routes and per-paper explanations of update targets, learning signals, persistence, evaluation, and review depth. It does not mirror another list or claim priority over related surveys.
