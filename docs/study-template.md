# A reusable reading note

[Overview](../README.md) · [Reading routes](reading-routes.md)

Copy this template into your own notes. Do not put private experiments or restricted material into a public pull request. The questions below are study prompts, not results from this collection.

```text
Paper / stable identifier:
Version and date read:
My learning question:

1. What problem does the agent face?
2. What exactly changes (and where is it stored)?
3. Who proposes the change: a fixed optimizer, the agent, or a learned improver?
4. Which information or feedback does the update use?
5. What survives a new task or session? What resets?
6. Which experiment supports the main claim?
7. What is the matched baseline, and is its budget comparable?
8. What is held out from learning, search, and selection?
9. What evidence shows transfer, retention, or failure?
10. What remains uncertain after reading?

One-sentence mechanism in my own words:
Strongest supported claim:
Claim I should avoid making:
Related papers and their differences:
An experiment I could run (proposed, not executed):
Artifact availability / license / cost notes:
```

If you later run an experiment, add the source commit, environment, model/version, prompts, task split, selection rule, budgets, seeds, raw outputs, and observed failures. Keep a reproduction attempt separate from a paper summary.
